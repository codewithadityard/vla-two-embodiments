# SPEC: one-week plan

## Project 1 (main): mini-VLA on LIBERO-Goal
Single embodiment (LIBERO, Franka, 7-D actions). Meta-World is cut for this week and goes in "next steps".
Model: frozen HuggingFaceTB/SmolVLM2-500M-Video-Instruct backbone (as in SmolVLA: use only the first half of the language-model layers; verify in lerobot/smolvla_base's config) + an action expert built from scratch.
Inputs: main + wrist camera, 8-D state, language instruction.
Action expert: small transformer (start: 6 layers, width 512) that cross-attends to backbone tokens and outputs an action chunk (start: 50 x 7; verify against SmolVLA's LIBERO settings).

Ablation configs (2 seeds each = 6 models):
- A: language + flow-matching head (main)
- B: no language (empty instruction) + flow-matching head
- C: language + regression (L1) head

Evaluation: lerobot-eval-style closed loop on libero_goal, all 10 tasks, 5 episodes per task to start (more if the budget allows), fixed eval seeds, Wilson 95% CIs. Always evaluate the final checkpoint at a fixed step count. Never pick checkpoints using eval results.

## Project 2 (smaller, days 4-5): DINO-WM reproduction on Wall
Use the official DINO-WM code and data (OSF, wall_single, 1.67 GB) at a reduced budget. Report planning success vs. the paper's number honestly. Separate spec later.

## Measured constraints (feasibility runs 1 and 2)
- Kaggle T4: frozen backbone 1.79 GB GPU, 0.357 s/step at batch 16 (random inputs); LoRA 3.39 GB, 0.544 s/step.
- One LIBERO episode with smolvla_libero: about 78 s on a T4. Evaluation cost matters as much as training.
- GPU budget: ~30 h this week. Keep docs/gpu_ledger.md with every Kaggle run (date, purpose, minutes).
- Kaggle: Python 3.13, MuJoCo 3.8.1 (LIBERO numbers with MuJoCo 3.x are not directly comparable to published 2.3.7 numbers; note in limitations).
- Laptop: code, tests and tiny runs only. Real runs go on Kaggle with Save & Run All (Commit).

## Milestones for Project 1 (one at a time, plan first, my approval each time)
M1 Data report (LIBERO-Goal only): episodes per task, episode lengths, fps, camera keys and sizes, state/action dims and ranges, instruction strings, normalization stats. Seeded train/val split by episode. Output: docs/data_report.md.
M2 Backbone features: decide caching vs. online from measured token counts and storage (limit 15 GB, keep per-token features, no pooling unless justified). Test: cached features match an online forward pass on 10 samples.
M3 Action expert + regression head. Tests: overfits a tiny batch; output shapes correct. Short training run, validation L1 logged.
M4 Flow-matching head (as in SmolVLA/pi0: linear path, velocity prediction, ~10 Euler steps at inference). Same tests.
M5 Closed-loop LIBERO eval of config A, seed 0. Measure seconds per episode. Use this to set the final episode budget.
M6 Ablation grid A/B/C x 2 seeds, with results table and CIs generated by script.
M7 README: results, 2-3 rollout videos, limitations, next steps (Meta-World second embodiment, LoRA, world-model action selection).
