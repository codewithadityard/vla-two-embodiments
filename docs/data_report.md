## State layout

**Verdict: axis-angle in dims 3-5 + two mirrored gripper fingers in dims 6-7 (SAME as the env's layout).**

The env (`lerobot/sim/integrations/libero.py` at the pinned LeRobot commit) builds the state as eef position (3) + axis-angle (3) + gripper finger qpos (2). The dataset's metadata names say `x, y, z, rx, ry, rz, rw, gripper`, so we test the values instead of trusting the names. M2 checks this directly: an env reset on Kaggle is compared with the first frame of a dataset episode.
